# 実地棚卸支援ツール

在庫リストを取り込み、複数人が同時にスマホからカウント結果を入力でき、集めた結果を取り込んだ在庫リストと同じ形のまま出力する、実地棚卸をまるごとサポートする無料ツールです。

## 公開URL
https://onuma-spec.github.io/tanaoroshi-tool/

## 構成
- `index.html` — ツール本体（管理者モード／カウント担当者モード、単一HTMLファイル）
- `gas_template.gs` — 集計先となるGoogle Apps Scriptのテンプレート（ツール内からもコピーできます）
- `サンプル在庫リスト.csv` — 動作確認用のサンプルデータ

## 仕組み
1. 管理者がツールで在庫リストを取り込み、各社自身のGoogleスプレッドシート＋GASに送信
2. 発行されたQRコード・リンクをカウント担当者に共有
3. カウント担当者がスマホで実地カウントした数量を入力・送信
4. 差異の確認・是正、最終結果の出力はGoogleスプレッドシート側で完結

データは各社自身のGoogleアカウント内にのみ保存され、本ツール（GitHub Pages）側には一切残りません。
